# Floating Point

## Fractional Binary Numbers

Bits left of the *binary point* have weights $2^{i}$; bits right of it have weights $\frac{1}{2}^{i}$. 

So $101.11_{2} = 4 + 0 + 1 + \frac{1}{2} + \frac{1}{4} = \frac{23}{4}$.
